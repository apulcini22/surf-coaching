dataLayer Events

Push QA events with large numbers of custom properties to window.dataLayer

Custom Property Events

Click a button to push the corresponding event to window.dataLayer. Open your browser console or GTM Preview to inspect the payload.

Flat Properties

qa_test_event — 50 properties

One event with 50 top-level properties named custom_prop_1 through custom_prop_50. 

const customProps = {};
for (let i = 1; i <= 50; i++) {
  customProps[`custom_prop_${i}`] = `value_${i}`;
}

window.dataLayer.push({
  event: "qa_test_event",
  ...customProps
});
Pushed to dataLayer
Stress Test

qa_test_event — 200 properties

Large flat payload for checking parameter limits and truncation in GTM and downstream tags. 

{
  event: "qa_test_event",
  custom_prop_1: "value_1",
  ...
  custom_prop_200: "value_200"
}
Pushed to dataLayer
Configurable

qa_test_event — custom count

Choose how many top-level properties to generate, then push a single event containing all of them. 

const customProps = {};
for (let i = 1; i <= count; i++) {
  customProps[`custom_prop_${i}`] = `value_${i}`;
}

window.dataLayer.push({
  event: "qa_test_event",
  ...customProps
});
Pushed to dataLayer
Nested Object

qa_test_event_nested

Same 50 properties, but nested under a single custom_props object instead of the top level. 

window.dataLayer.push({
  event: "qa_test_event_nested",
  custom_props: {
    custom_prop_1: "value_1",
    ...
    custom_prop_50: "value_50"
  }
});
Pushed to dataLayer
Mixed Types

qa_test_event_typed

50 properties cycling through string, number, boolean, null, array and object values to test type handling. 

{
  event: "qa_test_event_typed",
  custom_prop_1: "value_1",
  custom_prop_2: 2,
  custom_prop_3: true,
  custom_prop_4: null,
  custom_prop_5: ["value_5"],
  custom_prop_6: { nested: "value_6" },
  ...
}
Pushed to dataLayer
Burst

qa_test_event — burst

Push several events back to back, each with 50 properties plus a burst_index, to test rapid successive pushes. 

for (let n = 1; n <= count; n++) {
  window.dataLayer.push({
    event: "qa_test_event",
    burst_index: n,
    ...customProps
  });
}
Pushed to dataLayer
Long Values

qa_test_event_long_values

50 properties whose values are 500 characters each, useful for checking value length limits and truncation. 

customProps[`custom_prop_${i}`] =
  `value_${i}_` + "x".repeat(500);
Pushed to dataLayer
